# 公众号文章创作 Skill

一个面向中文微信公众号内容创作的 Codex Skill，覆盖选题、资料核验、标题设计、正文写作、旧稿修订、风格适配与发布前终审。

它的目标不是批量生成套路化“爆款”，而是在尊重用户材料和事实边界的前提下，把一个模糊想法逐步发展成结构清楚、信息可信、表达自然、适合手机阅读的公众号文章。

## 项目特点

- **完整创作链路**：从选题和任务定义开始，经过资料核验、标题确认、正文起草与终审，最终交付可直接使用的净稿。
- **按任务加载规则**：选题、写作、修订、事实核验和质量检查分别由独立参考文件负责，简单任务不会加载无关流程。
- **保留用户控制权**：完整新文章和大幅重写默认分阶段确认；用户也可以明确授权直接完成。
- **重视事实可靠性**：涉及人物、政策、产品、日期、数据和引语时，会按任务需要核验当前资料。
- **区分润色与重写**：润色尽量保留原结构和事实覆盖；重写允许重建表达与结构，但不擅自改变核心立场。
- **减少 AI 腔**：通过控制句长、节奏、逻辑连接、重复表达和空泛结论，让文章更接近自然的人类写作。
- **保护原创性**：参考材料用于核验和启发，不复制第三方的独特表达、标题套路、故事或观点。

## 适用场景

这个 Skill 适合：

- 根据账号领域和目标读者推荐公众号选题；
- 把一个主题发展成完整文章；
- 为已有正文重新设计文章总标题；
- 润色旧稿，改善逻辑、过渡、节奏和可读性；
- 在保留事实与核心观点的前提下重写旧稿；
- 核验热点、政策、产品、人物、日期、数据或引语；
- 根据用户提供的样本适配宽泛风格；
- 在发布前检查事实、标题兑现、结构、原创性和阅读体验；
- 单独完成短通知、句段、列表、标题或审校任务。

它主要面向中文微信公众号文章，不以学术论文、小说或独立商业推广文案为主要用途。

## 工作方式

### 完整文章与大幅重写

默认流程包含两个确认节点：

1. 明确主题、读者、目标、立场、语气、篇幅、材料范围和交付格式；
2. 形成创作任务书并等待确认；
3. 核验材料与时效信息；
4. 提供少量差异明确的文章名字及对应内容方向；
5. 确认标题和内容承诺；
6. 完成正文；
7. 检查事实、结构、原创性、标题兑现和自然表达；
8. 交付公众号净稿。

如果用户明确说明“直接写”“不用确认”或授权全过程代决，Skill 会在内部完成必要核对后直接交付。只授权某一个环节时，仅跳过该环节的等待。

### 限定范围任务

只需要选题、标题、句段、列表、短通知或审校时，Skill 会按指定范围直接完成，不自动扩展成整篇文章。用户要求仅审校时，默认提供问题位置、判断依据和修改建议，不擅自改写全文。

### 润色与重写

| 模式 | 适用情况 | 默认保留 | 允许调整 |
| --- | --- | --- | --- |
| 润色 | 内容和结构基本可用 | 章节顺序、事实覆盖、核心观点 | 措辞、逻辑衔接、节奏、可读性 |
| 重写 | 方向成立但表达或结构需要重建 | 可核验事实、真实经历、核心立场 | 开头、论证顺序、章节结构、标题和结尾 |

## 篇幅选项

| 档位 | 正文字数 | 内容侧重 |
| --- | ---: | --- |
| 精简版 | 800—1500 | 集中回答一个问题，保留关键理由与必要条件 |
| 标准版 | 1800—3000 | 展开解释、案例或方法，让读者看清判断依据 |
| 深度版 | 3000—5000 | 深入机制、比较不同条件，并处理可能改变结论的反例 |

字数默认按正文非空白字符计算，包含中英文、数字、标点和内部标题；总标题、来源链接与稿外说明不计入。

## 安装

保留完整的 `wechat-article-writing` 文件夹，并将它复制到以下任一位置。安装完成后，`SKILL.md` 应位于该文件夹根目录。

仅在一个项目中使用：

```text
<项目目录>/.agents/skills/wechat-article-writing
```

在个人的所有项目中使用：

```text
$HOME/.agents/skills/wechat-article-writing
```

Windows 也可以使用：

```text
%USERPROFILE%\.agents\skills\wechat-article-writing
```

如果安装后没有立即出现，可以重启 Codex。更多背景可参考 [OpenAI Codex Skills 文档](https://learn.chatgpt.com/zh-Hans/docs/build-skills)。

## 快速开始

当请求符合用途时，Codex 可以自动调用这个 Skill。也可以使用名称明确指定：

```text
$wechat-article-writing 我想写一篇关于家庭教育的公众号文章，请从确认方向开始。
```

直接完成完整文章：

```text
$wechat-article-writing 为工作三到五年的职场人写一篇关于“下班后的社交是否值得参加”的公众号文章。标准版，角度和标题由你决定，不用等待确认；核对材料并终审后直接给出净稿。
```

推荐选题：

```text
$wechat-article-writing 我的账号关注个人成长，读者主要是 25 到 35 岁的职场人。请推荐 5 个值得写的选题。
```

润色旧稿：

```text
$wechat-article-writing 帮我润色这篇旧稿，保留章节顺序和全部事实，只改善表达、逻辑与阅读节奏。
```

核验热点内容：

```text
$wechat-article-writing 根据最近公布的这项政策写一篇热点解读。先核验政策原文、发布日期和适用范围，再确认文章角度。
```

适配样本风格：

```text
$wechat-article-writing 参考我提供的三篇文章，只提炼句长、节奏、正式程度和叙事方式，不复制原句或独特表达。
```

## 默认交付形式

完整文章默认以净稿形式交付：

- 第一行是文章总标题；
- 正文采用适合手机阅读的短段落；
- 只在确有导航价值时使用内部小标题；
- 不附带内部大纲、评分、搜索过程或聊天机器人开场白；
- 不把资料缺口、虚构练习或假设场景包装成真实经历；
- 外部核验自然融入正文，需要引用时将来源与净稿分开提供。

## 事实、素材与原创性边界

- 不为增强传播性而虚构数据、热度、案例、引语、产品体验或第一人称经历。
- 明确区分用户提供的事实、基于事实的解释和给读者的建议。
- 外部事实使用适合的来源；可能随时间变化的信息优先核验当前有效版本。
- 材料不足时会说明具体缺口或建议缩短篇幅，不用重复扩写填满字数。
- 用户提供的旧稿按授权范围处理，不把“润色”自动升级为重写。
- 作者样本只用于学习宽泛风格，不模仿其身份、故事、独特表达或固定标题套路。
- 产品体验和测评必须基于真实经历或可靠材料；证据不足时只做中性说明。

## 设计原则

1. **先尊重任务范围**：只交付用户要求的产物，不擅自扩大任务。
2. **先核验再下结论**：涉及外部事实和当前信息时，证据优先于表达力度。
3. **篇幅服务于内容**：增加字数用于深化信息，而不是重复同一结论。
4. **标题必须兑现**：标题提出的问题、承诺和读者收益需要在正文中得到回应。
5. **终审必须实际修正**：发现可解决的问题时直接修复，不只生成检查清单。
6. **简单任务保持简单**：按需读取参考文件，减少无关流程和上下文负担。
